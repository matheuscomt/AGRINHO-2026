# AGRINHO 2026

Projeto desenvolvido para a atividade da categoria Front-End.

## Tema

Agro forte, futuro sustentável: equilíbrio entre produção e meio ambiente.

## Sobre o projeto

Este site fala sobre a importância do agronegócio para o Brasil e mostra como a tecnologia pode ajudar na produção de alimentos sem prejudicar o meio ambiente.

O objetivo é apresentar informações simples sobre sustentabilidade no campo, uso consciente da água, preservação do solo e tecnologias que ajudam o produtor rural.

## O que o site apresenta

- Importância do agronegócio
- Sustentabilidade no campo
- Tecnologias sustentáveis
- Desafios ambientais
- Mensagem de conscientização

## Tecnologias usadas

- HTML
- CSS
- JavaScript
